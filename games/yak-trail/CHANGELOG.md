# Yak Trail — changelog

One short entry per change the user can play, newest first: what changed, the decision numbers behind
it, and how to see it. This is the only place a change is summarized — other files link here.

## 2026-11-02 — the first playable climb
- The whole demo: title, one trail from meadow through rocks to snow, hops, tufts to munch, cairns as
  checkpoints, birds, the summit and its panel, pause with Help and a timer switch, the best time kept
  (#1–#6). Play it from the studio (Games → Yak Trail → Play).
- The text and the boxes are art: the font and the UI widgets show in the Art view and can be repainted.
